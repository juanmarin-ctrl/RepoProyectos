# Proyecto: AV Studio Academy (América Villasmil)

**Primer proyecto del Site Kit** — caso cerrado de referencia.  
Nuevos clientes **no** deben clonar su look (ver `../../design/anti-template.md`).

| | |
|--|--|
| Marca | AV Studio Academy / América Villasmil |
| Rubro | Formación en tricología cosmética, color y química capilar |
| Entrega | WordPress + Elementor (plugin instalador propio) |
| Dominio | abstudioacademy.com |

## Contenido de esta carpeta

| Ruta | Qué es |
|------|--------|
| `brief/documentos/` | Empresa, acerca, plan de estudios, branding, POE, extracts |
| `brief/imagenes/banco-original/` | Banco de fotos del cliente |
| `brief/branding-preview/` | Previews del manual / estilos |
| `mockup/web/` | Mockup HTML de referencia |
| `entrega-wordpress/` | Paquete de entrega + **AV Studio Maestro** (`av-studio-importer`) |
| `payload/` | Reservado si se regenera con Site Maestro genérico |
| `concepto.md` | Experiencia usada (para que otros proyectos se alejen de ella) |

## Instalación (legacy)

Sigue `entrega-wordpress/UN-SOLO-CLICK.md` y el ZIP de `av-studio-importer`.  
Este proyecto **no** usa aún el motor genérico `engine/site-maestro` (nació antes del kit).
